# 🚃 えきタイマー

時間を「分」ではなく「駅」ではかるタイマーです。
山手線や大阪環状線の区間を選んで出発すると、駅に着くたびにチャイムやアナウンスが流れ、終点に着いたら時間です。

**▶ https://moritalous.github.io/eki-timer/**

## 使い方

1. 路線（山手線／大阪環状線）を選ぶ
2. 輪の上の駅をタップ。1回目で乗る駅、2回目で降りる駅（同じ駅なら一周）
3. 輪の中で外回り・内回りを選んで「出発進行」

オプションはアイコンで切り替えます。設定と前回の区間はブラウザに保存されます。

| アイコン | 内容 |
|---|---|
| ベル | 効果音 → 効果音＋バイブ → バイブ → オフ |
| メガホン | 駅名のアナウンス |
| 音の波 | 走行音（ガタンゴトン） |
| 太陽 | 乗車中に画面をスリープさせない |
| 早送り | 通常 → 2倍速 → 4倍速 → 10倍速 |

## しくみ

ビルド不要の静的サイトです（HTML / CSS / JavaScript のみ）。

- 効果音・発車メロディ・走行音は Web Audio API でその場で合成したオリジナルです。発車メロディは駅ごとに自動で作曲されます。
- アナウンスはブラウザの読み上げ機能（Web Speech API）です。声は端末によって変わります。
- バイブは Vibration API、スリープ防止は Screen Wake Lock API を使っています。どちらも HTTPS で開いたときだけ使えます。iPhone の Safari はバイブに対応していません。

```
index.html
style.css
js/
  app.js       画面と運行（設定画面・乗車中・設定の保存）
  stations.js  駅データと経路の計算
  ring.js      楕円の路線図の描画
  sound.js     効果音・走行音・読み上げ・バイブ
```

## ローカルで動かす

ES Modules を使っているので、ファイルを直接開くのではなく、簡単なサーバー経由で開いてください。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。
